# Weather

A lightweight weather search site hosted with GitHub Pages. Search for a city to see current temperature, humidity, wind speed, and hourly forecast data from Open-Meteo. The forecast refreshes automatically every 10 minutes.

Once GitHub Pages is enabled for this repository, open **`/weather.html`** on the published site to use the live weather search (for example, `https://hammadurrehman777-ops.github.io/weather/weather.html`).

No API key or build step is required. City names are resolved with the Open-Meteo Geocoding API, and weather data comes from its Forecast API.
